# Reviewer walkthrough

## Ninety second portfolio tour

Open [the interactive gallery](index.html), then select **Projects**.

Begin with the NewsBot midterm. Explain that the professor approved historical BBC dataset retained 1,440 articles after cleaning. Point to the Linear SVM held out 96.53% accuracy and 96.45% macro F1, and immediately state that this is performance on one historical English corpus, not a general production guarantee.

Open the executed notebook and technical report to show the model comparison, an error analysis limitation and the distinction between classification, sentiment and named entity signals.

Switch to **Methods** and **Analysis** to show how the notebooks on preprocessing, representation, part of speech and sentiment provided the foundations for the integrated project.

Finish with the separate NewsBot 2.0 repository. Explain that it extends the work into web interaction, topic modeling, controlled multilingual study and an independently scoped evaluation. Synthetic demonstration data are clearly labeled.

## Five minute technical review

1. **Problem definition:** News categorization and interpretable media monitoring.
2. **Provenance:** Source BBC training CSV, exclusions, retained classes and dataset rights.
3. **Design:** Separate normalized text for modeling and preserved original text for context sensitive linguistic analysis.
4. **Comparison:** Stratified split, cross validation, macro F1 and baseline.
5. **Failure modes:** Technology recall, editorial sentiment, dataset shift and entity errors.
6. **Engineering:** Colab dependency troubleshooting, source verification and portfolio documentation.
7. **Extension:** NewsBot 2.0 modules, test infrastructure and deliberately separate research evidence.
8. **Professional relevance:** A future qualified review workflow in scientific or pharmaceutical intelligence, not an existing validated product.
